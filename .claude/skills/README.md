# Skills

이 폴더는 이 워크스페이스 전용 스킬을 담습니다.

## Skills란?

Skills는 Claude Code가 **키워드 기반으로 자동 트리거**하는 기능 모음입니다.
구 슬래시 커맨드 방식(`/daily-note`)을 대체합니다.

- 자연어 호출: "오늘 daily note 만들어줘"
- Claude가 description에 있는 키워드를 감지하여 자동 실행
- 각 스킬은 `SKILL.md`를 루트에 두고, 필요시 `scripts/`, `resources/` 같은 하위 폴더 사용

## 파일 구조

```
.claude/skills/
├── README.md             # 이 파일
└── [skill-name]/
    ├── SKILL.md          # 스킬 정의 (YAML frontmatter + 설명 + 실행 절차)
    ├── scripts/          # (선택) 실행 스크립트
    └── resources/        # (선택) 참고 자료, 템플릿
```

## SKILL.md 구조

```yaml
---
name: skill-name
description: 이 스킬이 언제 트리거되는지 명확히. "X를 언급하면 자동 실행" 형식 권장.
---

# 스킬 제목

본문 — 실행 절차, 예시, 주의사항
```

## 전역 vs 프로젝트 스킬

- **전역**: `~/.claude/skills/` — 모든 프로젝트에서 적용
- **프로젝트**: 이 폴더 — 이 워크스페이스에서만 적용

프로젝트 스킬이 전역 스킬과 이름이 같으면 프로젝트 것이 우선.

## 포함된 스킬 (32개)

이름을 외울 필요는 없습니다. 한국어로 말하면 걸립니다 — "카톡 읽어줘" 하면 `kakao-read`가 뜹니다.
아래 **부르는 말**은 그 스킬이 확실히 걸리는 문장이고, 비슷하게 말해도 대개 걸립니다.

### 처음 한 달에는 이 다섯 개만

32개를 다 보면 아무것도 안 쓰게 됩니다. 매일 쓰는 것부터 몸에 붙이세요.

1. `setup-workspace` — 받은 직후 딱 한 번. 이걸 안 하면 다른 스킬이 폴더를 못 찾습니다
2. `daily-note` — 오늘 업무일지를 정해진 폴더에 만듭니다. 하루의 시작
3. `todo` — "이거 해야 해" 한 마디로 할 일이 담깁니다
4. `thinking-partner` — 답이 아니라 질문이 필요할 때. 뭘 해야 할지 모르겠을 때
5. `ripple` — 대화를 닫기 전에 한 번. 오늘 한 일이 노트와 진행 로그에 나뉘어 적힙니다

나머지는 필요한 일이 생겼을 때 아래에서 찾으세요.

### 내 것 가져오기

#### 카톡 읽기 · `kakao-read`
내 컴퓨터 안에 있는 카카오톡에서 대화·사진·파일을 직접 읽어 옵니다. 카카오 서버에 접속하지 않습니다. 요약·검색·할 일 뽑기까지 한 번에 합니다.
- **부르는 말** "카톡 읽어줘" · "어제 그 방 대화 정리해줘" · "카톡에서 그 파일 찾아줘" · "카톡 체크"
- **조심할 것** 읽기 전용입니다 — 보내기·삭제는 안 됩니다. 사진·파일은 **보낸 지 3일 안쪽만** 받아집니다(카카오 정책이라 못 고칩니다). Mac은 `brew install sqlcipher`가 먼저고, 윈도우는 **카톡이 켜져 있어야** 합니다
- **누구에게** 영업·CS · 매장·자영업 · 팀장·관리자 · 총무·행정

### 조사하기

#### 네이버 검색 데이터 · `naver-search`
네이버 블로그·카페 글과 검색량을 정식 API로 가져옵니다. 이 키워드가 한 달에 몇 번 검색되는지, 사람들이 같이 검색하는 말이 뭔지, 글이 얼마나 쌓였는지가 숫자로 나옵니다.
- **부르는 말** "검색량 조회" · "연관키워드 뽑아줘" · "카페 수요 조사" · "키워드 경쟁강도"
- **조심할 것** 처음 한 번 키 발급이 필요합니다. 검색·트렌드만 쓰면 네이버 API HUB 하나, 검색량·연관키워드까지 쓰려면 검색광고 API도. **키는 본인 계정으로** 받으세요 — 남의 키를 쓰면 계정 공유가 됩니다
- **누구에게** 마케팅·홍보 · 이커머스·MD · 기획·전략 · 대표·창업

#### 리뷰 분석 · `review-analyzer`
네이버 리뷰를 로그인 없이 모아 4단계로 분석합니다. 무엇이 좋았고 무엇이 걸렸는지, 그래서 다음에 뭘 바꿀지까지 나옵니다. 상품 리뷰(브랜드스토어)와 매장 리뷰(플레이스·지도) 둘 다 됩니다.
- **부르는 말** "네이버 리뷰 분석해줘" · "경쟁사 리뷰 봐줘" · "우리 매장 플레이스 리뷰"
- **조심할 것** 상품 리뷰는 Chrome 브라우저가 필요합니다(selenium). 매장 리뷰는 아무것도 필요 없습니다
- **누구에게** 이커머스·MD · 매장·자영업 · 마케팅·홍보 · CS·품질

#### 웹페이지 저장 · `web-crawler-ocr`
웹페이지를 통째로 가져와 워크스페이스에 문서로 저장합니다. 페이지 안 이미지에 박혀 있는 글자까지 읽어냅니다.
- **부르는 말** "이 주소 워크스페이스에 저장해줘" · "아카이빙" · "이미지 OCR"
- **조심할 것** **저장하겠다고 말할 때만** 돕니다 — 주소만 주면 안 돕니다. 그냥 읽고 요약만 할 거면 이 스킬이 아닙니다. 이미지 글자 읽기에는 Gemini API 키가 필요합니다
- **누구에게** 마케팅·홍보 · 기획·전략 · 이커머스·MD · 교육·HR

#### 막힌 페이지 열기 · `web-bypass`
그냥은 안 열리는 페이지를 열두 가지 방법으로 돌아 들어가 내용만 뽑아 옵니다. 한 번 가져온 것은 하루 동안 저장해 두고 다시 씁니다.
- **부르는 말** "403이야 뚫어줘" · "차단됐는데 내용 가져와줘"
- **조심할 것** 처음 한 번 설치가 필요합니다 — `bash .claude/skills/web-bypass/scripts/install.sh`. 잘 열리는 주소에는 쓰지 않습니다
- **누구에게** 마케팅·홍보 · 기획·전략 · 이커머스·MD · 대표·창업

#### AI 답변에 인용되게 · `ko-geo`
내 글이 ChatGPT·퍼플렉시티 같은 AI 답변에 인용되도록 글을 고쳐 줍니다. 통계·인용·출처를 보강하는 방식이고, 바꾼 뒤 실제로 인용되는지 재는 것까지 합니다.
- **부르는 말** "GEO 최적화해줘" · "AI 검색에 잘 나오게" · "인용률 측정"
- **조심할 것** 고치고 진단하는 데는 아무 준비가 필요 없습니다. 인용되는지 자동으로 재는 것만 API 키가 필요하고, 손으로 재는 방식은 키 없이 됩니다
- **누구에게** 마케팅·홍보 · 콘텐츠·에디터 · 대표·창업 · 이커머스·MD

### 문서 바꾸기

#### 엑셀 → CSV · `excel-to-csv`
xlsx·xls 파일을 CSV로 바꿔 저장합니다. 원본을 여는 게 아니라 새 파일로 뽑아냅니다. 시트가 여러 장이면 시트별로 나뉩니다.
- **부르는 말** "엑셀 변환해줘" · "이 xlsx CSV로"
- **조심할 것** 한글이 안 깨지게 UTF-8로 저장합니다. 파이썬 준비가 필요합니다(`setup-workspace`가 해 둡니다)
- **다음 단계** 뽑은 CSV가 지저분하면 → `csv-clean`
- **누구에게** 영업·정산 · 생산·재고 · 기획·분석 · 사무·행정

#### CSV 정리 · `csv-clean`
표에 섞여 있는 소계 행, `3,000원` 같은 글자 숫자, 제각각인 날짜 표기를 정리합니다. 가로로 퍼진 월별 열을 세로로 세우는 것도 됩니다.
- **부르는 말** "데이터 정리해줘" · "소계 제거" · "날짜 통일"
- **앞 단계** 엑셀에서 시작한다면 → `excel-to-csv` 먼저
- **누구에게** 영업·정산 · 생산·재고 · 기획·분석 · 마케팅·홍보

#### PDF → 글 · `pdf-to-md`
PDF를 표·제목·문단 구조를 살린 채 텍스트로 바꿉니다. 그냥 열어 읽는 것보다 표가 안 깨지고, 몇백 쪽짜리도 한 번에 넘어갑니다.
- **부르는 말** "PDF를 마크다운으로" · "이 PDF 텍스트 뽑아줘"
- **조심할 것** 변환은 파이썬이 하므로 대화 분량(토큰)을 잡아먹지 않습니다
- **누구에게** 기획·전략 · 디자인 · 생산·품질 · 사무·행정

#### 글 → 인쇄용 · `md-to-pdf`
정리된 글을 A4 한 장씩 끊어지는 인쇄용 화면으로 바꿉니다. 검은 바탕의 미니멀 디자인이고, 글이 페이지 밖으로 넘치지 않게 자동으로 맞춥니다.
- **부르는 말** "핸드아웃 만들어줘" · "배포용으로" · "A4로 뽑아줘"
- **조심할 것** **PDF 파일이 바로 나오지 않습니다.** HTML이 나오고, 브라우저에서 인쇄(PDF로 저장)를 누르면 PDF가 됩니다
- **누구에게** 교육·HR · 기획·전략 · 마케팅·홍보 · 대표·팀장

#### 녹취 정리 · `transcript-organizer`
강의·미팅·인터뷰를 받아쓴 긴 텍스트를 구조를 잡아 정리합니다. 음성인식이 잘못 알아들은 말을 고치고, 글자가 깨진 파일도 살립니다.
- **부르는 말** "녹음 정리해줘" · "미팅록 만들어줘" · "이 txt 정리"
- **조심할 것** **녹음을 글로 바꾸는 건 이 스킬이 아닙니다.** 이미 받아쓴 txt를 넣으면 정리된 문서가 나옵니다. 임의로 줄이지 않고 원문 인용을 많이 남깁니다
- **누구에게** 교육·HR · 기획·전략 · 마케팅·홍보 · 대표·팀장

### 매일 기록

#### 데일리 노트 · `daily-note`
오늘 날짜 업무일지를 정해진 폴더에 만듭니다. 구글 캘린더를 연결해 두면 오늘 일정이 그 안에 같이 적혀 나옵니다.
- **부르는 말** "오늘 daily note" · "하루 기록 시작"
- **조심할 것** 이미 오늘 노트가 있으면 새로 만들지 않고 그 파일을 엽니다. 캘린더 연결(`gws`)은 선택입니다 — 없으면 일정 칸만 빕니다
- **누구에게** 기획·운영 · 대표·팀장 · 인사·교육 · 프리랜서

#### 데일리 리뷰 · `daily-review`
어제부터 오늘까지 실제로 바뀐 파일을 훑고, 오늘 노트와 담아 둔 할 일을 같이 봐서 무엇을 먼저 할지 순서를 매깁니다.
- **부르는 말** "일일 리뷰" · "오늘 뭐 했지" · "어제 작업 정리"
- **조심할 것** 바뀐 파일은 git으로 봅니다. git으로 관리하지 않는 폴더면 노트와 할 일만 봅니다
- **누구에게** 기획·운영 · 대표·팀장 · PM·PO · 프리랜서

#### 주간 정리 · `weekly-synthesis`
한 주 동안의 기록과 작업을 모아 하나로 묶습니다. 무엇을 했는지가 아니라 무엇이 남았는지가 나옵니다.
- **부르는 말** "주간 정리" · "이번 주 회고"
- **조심할 것** 금요일이나 일요일에 한 번 돌리는 용도입니다
- **누구에게** 대표·팀장 · 기획·운영 · 인사·교육 · 프리랜서

#### 할 일 넣기 · `todo`
말하는 대로 할 일을 담습니다. 급한 것인지, 어느 프로젝트 것인지 알아서 붙여 둡니다.
- **부르는 말** "이거 해야 해" · "기억해둬" · "할 일 추가"
- **누구에게** 전 직군

#### 할 일 보기 · `todos`
담아 둔 할 일을 꺼내 봅니다. 전체·오늘·프로젝트별·오래 묵은 것으로 나눠 보고 통계도 나옵니다.
- **부르는 말** "할 일 보여줘" · "오늘 할 일" · "오래된 할 일"
- **조심할 것** 마감일 개념은 없습니다. **담아 둔 지 1주일이 넘은 것**을 "오래된 것"으로 모아 봅니다
- **누구에게** 전 직군

### 지식 쌓기

#### 위키에서 찾기 · `wiki-query`
쌓아 둔 위키에서 찾아 인용과 함께 답합니다. 주제·개념·과거 판단을 물으면 따로 부르지 않아도 켜집니다.
- **부르는 말** "위키에서 찾아줘" · "우리가 뭐라고 정리했더라"
- **조심할 것** 위키는 원본이 아니라 정리본입니다. 방향·판단은 그대로 써도 되지만 금액·날짜·이름은 근거에 적힌 원본 파일까지 열어 확인합니다
- **누구에게** 기획·전략 · 교육·HR · 대표·창업 · 콘텐츠·에디터

#### 위키에 쌓기 · `wiki-ingest`
흩어진 자료를 읽어서 주제별 위키 문서에 합칩니다. 덧붙이기만 하는 게 아니라 핵심을 다시 쓰고, 서로 연결하고, 앞뒤가 안 맞는 곳을 표시합니다.
- **부르는 말** "위키에 반영해줘" · "지식 축적"
- **조심할 것** 아는 것이 파일 개수가 아니라 한 장의 정리로 쌓입니다. `transcript-organizer`가 끝에서 이 스킬을 부릅니다
- **누구에게** 기획·전략 · 교육·HR · 대표·창업 · 콘텐츠·에디터

#### 위키 점검 · `wiki-lint`
쌓아 둔 위키를 훑어 문제를 찾습니다. 아무 데서도 연결 안 된 문서, 끊어진 링크, 오래 손 안 댄 문서, 서로 어긋나는 내용을 짚습니다.
- **부르는 말** "위키 점검" · "위키 헬스체크"
- **조심할 것** 한 달에 한 번쯤이면 충분합니다
- **누구에게** 기획·전략 · 교육·HR · 대표·창업 · 콘텐츠·에디터

## 헷갈리는 짝

이름만 보면 비슷해 보이는 것들입니다. 갈리는 지점만 적었습니다.

**`naver-search` vs `review-analyzer`** — 앞은 **검색 데이터**(몇 명이 뭘 검색하는지), 뒤는 **리뷰**(산 사람이 뭐라고 했는지). 시장이 있는지 보려면 앞, 무엇을 고칠지 찾으려면 뒤.

**`web-crawler-ocr` vs `web-bypass` vs 그냥 요약** — 저장할 거면 앞, 막혀서 안 열리면 가운데, 읽고 요약만 할 거면 **둘 다 아닙니다**(그냥 주소를 주고 요약해달라고 하면 됩니다).

**`todo` vs `todos`** — 단수는 **넣기**, 복수는 **보기**. 헷갈리면 "할 일 추가"·"할 일 보여줘"로 말하면 알아서 갈립니다.

**`daily-review` vs `weekly-synthesis`** — 앞은 **오늘 뭘 먼저 할지**(아침), 뒤는 **한 주에 뭐가 남았는지**(주말).

**`transcript-organizer` vs 녹음 앱** — 이 스킬은 **이미 글로 받아쓴 파일**을 정리합니다. 음성을 글로 바꾸는 건 폰 녹음기나 받아쓰기 앱이 합니다.

## 설치가 필요한 스킬 (파이썬 패키지)

- `csv-clean` — pandas
- `excel-to-csv` — openpyxl
- `pdf-to-md` — pymupdf4llm

- `naver-search` — **없음** (파이썬 표준 라이브러리만). 대신 API 키가 필요하다: NAVER API HUB(ncloud) 필수, 검색광고 API(searchad.naver.com)는 검색량·연관키워드를 쓸 때만. `scripts/.env.example`을 `.env`로 복사해 채운다 — 키는 각자 본인 계정으로 발급
- `web-bypass` — **스킬 안에 자체 venv를 만든다.** 처음 쓰기 전 1회 `bash .claude/skills/web-bypass/scripts/install.sh` (curl_cffi·bs4·pyyaml). 멱등성이 있어 여러 번 돌려도 안전하다. 차단이 심한 사이트까지 다루려면 `--with-playwright`(~300MB), Cloudflare/DataDome 챌린지를 실제로 통과해야 하면 `--with-cloak`(~200MB)를 붙인다. venv는 `.gitignore` 대상이라 받은 압축 파일에는 포함되지 않는다 — 각자 설치해야 한다

## 설치가 필요한 스킬 (시스템 도구·플랫폼)

- `kakao-read` — **Mac·윈도우 둘 다 됩니다. 읽는 방식이 다릅니다.** Python 패키지 의존은 없음(양쪽 다 표준 라이브러리만).
  - **Mac**: 카톡의 암호화된 로컬 DB를 직접 읽습니다. 시스템 도구 `sqlcipher`가 필요:
  ```bash
  brew install sqlcipher
  # 최초 1회 본인 userId 캐시 (워크스페이스 루트에서)
  python3 .claude/skills/kakao-read/scripts/kakao_read.py setup
  ```
  카카오톡 데스크톱 앱에 한 번 이상 로그인돼 있어야 한다. 설정은 `~/.config/kakao-read/`(HOME)에 저장 — 워크스페이스 밖이라 git 추적 안 됨.
  - **윈도우·WSL**: 실행 중인 카톡의 메모리를 읽습니다. `sqlcipher`도 키도 필요 없고, **읽는 순간 카톡이 켜져 있어야** 합니다. 윈도우에는 파이썬이 기본으로 없으니 없으면 먼저 설치하세요(`winget install --id Python.Python.3.12 -e`). 절차는 SKILL.md의 "윈도우 카톡 읽기" 절에 있습니다.
  - 그 밖의 OS(순수 리눅스)에서는 안 됩니다 — 다른 스킬엔 영향 없습니다.
- `ko-geo` — 변환·진단은 의존성 0. 모니터링 **수동 모드(manual)도 키 0개**(표준 라이브러리만). **자동 모드(run)**만 API 키 필요 — `scripts/.env`에 `PERPLEXITY_API_KEY`/`GEMINI_API_KEY`(Gemini는 무료 티어 가능). `python-dotenv`는 있으면 쓰고 없으면 환경변수로 대체(graceful).

**권장 세팅 (워크스페이스 전용 venv)**:

```bash
# 워크스페이스 루트에서 1회 실행
python3 -m venv .venv        # 윈도우 Git Bash에는 python3 가 없을 수 있다 → python 또는 py
source .claude/venv.sh
python -m pip install -r .claude/skills/csv-clean/scripts/requirements.txt -r .claude/skills/excel-to-csv/scripts/requirements.txt -r .claude/skills/pdf-to-md/scripts/requirements.txt
```

이후 Python 스킬을 쓸 때마다 `source .claude/venv.sh` 한 번 실행 (Mac·윈도우 공통). 활성화 뒤에는 `python3`가 아니라 **`python`**으로 부른다. `.venv/`는 `.gitignore` 처리됨.

**venv 없이 직접 설치하려면** (Python 3.12+ / Homebrew 환경에서는 PEP 668 때문에 실패할 수 있음):

```bash
python -m pip install -r .claude/skills/csv-clean/scripts/requirements.txt
# 실패 시: python -m pip install --user ... 또는 pipx 고려
```
