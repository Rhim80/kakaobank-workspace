# <이름> — 내 수집 스킬

규약은 `.claude/skills/wiring/references/declaration.md` 「실행 명령」이 원본이다. 이 파일에는 경로·호출·명령을 적지 않는다 — 전부 `00-system/wiring/선언.yaml`과 `실행상태.yaml`에서 읽는다.

1. `선언.yaml`의 `통로`와 `실행상태.yaml`의 `수집.<통로id>.이어받기`를 읽는다.
2. 통로마다 `길`에 따라:
   - `MCP`: `호출.도구`를 `호출.인자`로 부르되 `범위`에 적힌 방법으로 `이어받기` 이후만 조회한다. 건마다 본문을 임시 파일에 두고 `wiring.sh store <통로id> '<고유키>' <임시파일>`로 등록한다.
   - `CLI`: `호출.argv`를 그대로 Bash로 실행한다(인자를 고쳐 쓰지 않는다). 등록은 위와 같다.
   - `직접 넣기`: `wiring.sh intake <통로id>` 한 줄.
3. 통로마다 `wiring.sh result <통로id> --ok --cursor '<이번에 처리 완료한 끝 지점>' --count <신규등록 true 건수>`. 조회나 등록이 하나라도 실패했으면 `--error '<원문>'`으로 남기고 `--ok`를 쓰지 않는다.
4. 마지막에 통로마다 한 줄: `신규 N건` / `신규 0건` / `실패: <이유>`. 실패를 0건으로 적지 않는다.

하지 않는 것: 원본함 파일 고치기, 제안 만들기, 기록 파일·할 일 쓰기. 그건 morning과 병목 스킬의 일이다.
