# <이름> — 내 병목 스킬

규약은 `.claude/skills/wiring/references/declaration.md` 「병목 스킬과 morning의 연결」이 원본이다.

입력: Skill 인자로 받은 자료 id들(공백 구분). id마다 `00-system/wiring/실행상태.yaml`의 `자료.<id>.원본`을 읽는다.
출력: 자료 id마다 `00-system/wiring/제안/<자료id>.md` **한 파일만** 쓴다. 이미 있으면 덮어쓰지 않고 그대로 둔다.

제안 파일에 적는 것 — 줄기 · 항목(여럿이면 번호) · 반영할 내용 한 줄(원문 어휘 그대로) · 성격(기록/할 일/일정/알아둘 것/버림) · 원문 근거 줄 · 반영 위치 · <이 병목의 산출물: 답변 초안·정리본 등>. 근거를 못 찾으면 "근거 없음 — 본인 확인 필요"라고 적고 지어내지 않는다.

하지 않는 것: 원문 수정, `status` 호출, 기록 파일·할 일·캘린더·회사 시스템 쓰기. 승인 뒤 반영은 morning이 한다. `allowed-tools`는 미리 허용일 뿐 접근 금지를 강제하지 않는다.
