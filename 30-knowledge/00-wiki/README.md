# 00-wiki 운영 가이드

> Karpathy "LLM Wiki" 아이디어 기반. 지식을 복리로 축적.
> 규칙은 `SCHEMA.md`, 토픽 카탈로그는 `index.md`, 활동 기록은 `log.md`.

## 핵심 아이디어

- **단순 축적이 아닌 통합**. 같은 소스에서 여러 토픽이 동시에 enriched 되어야 복리.
- **기존 페이지 확장 우선**. 비슷한 토픽 있으면 새 파일 만들지 말 것.
- **출처 인용 필수**. 모든 추가에 [source: 출처, 날짜].
- **모순은 삭제 금지**. 열 때 `[!contradiction 날짜]`, 판정되면 `[!superseded 날짜 → 이긴 근거]`로 닫는다. 판단은 사용자.

## 사용 흐름

1. **Query**(`wiki-query`) — 주제에 대해 물으면 `index.md` → `Grep` → `Read` 순으로 확인하고 인용과 함께 답한다. 따로 부르지 않아도 켜진다
2. **Ingest**(`wiki-ingest`) — 소스가 쌓이면 "위키에 반영해줘"로 토픽 페이지에 통합
3. **Lint**(`wiki-lint`) — 가끔 "위키 점검"으로 헬스체크. 불러야 돈다(자동으로 도는 자리는 없다)
