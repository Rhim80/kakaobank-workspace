## 상황 설정

**9월 21일 월요일, 오전 8시 40분. 판교.**

주말이 지나고 첫 출근. 커피를 내려놓고 노트북을 연다. 월요일 아침은 늘 같다 — 금요일 마감실적이 와 있고, 타행 금리는 주말 사이 누가 바꿨는지 모르고, 은행채는 금요일 고시분을 봐야 한다.

코코 알림이 울린다.

> **팀장님**: 혜주님, 좋은 아침이에요
>
> 금요일 마감 요약 9시 반 전에 부탁해요
> 내일 ALM협의회라 본부장님이 오늘 은행채 흐름이랑 수신 쪽 같이 보자고 하셨어요
> 은행채 1년물이 2주째 오르고 있어서 그 얘기가 먼저 나올 것 같아요

**(속으로)**: 9시 반이면 50분. 사이트 몇 개 돌고 양식에 옮기면 절반이 간다. 이슈 없는 날이면 괜찮은데.

코코가 또 온다.

> **아일라님** (넥스트주담대팀): 혜주님~ 주말 잘 보내셨어요?
>
> 저 월초 실적 예상에 금융환경 파트 넣으려는데
> 수신 쪽은 요즘 금리 흐름 어떻게 보고 계세요?
> 은행채 올라가는 거 저희도 신경 쓰여서요. 정리되면 한 줄만 나눠주세요

**(속으로)**: 같은 숫자를 팀장님, 본부장님, 아일라님이 각자 다른 이유로 기다린다. 그리고 셋 다 "그래서 왜?"를 물을 거다.

- 진짜 마감: 9시 30분 팀장님 요약
- 체감 마감: 9시 10분 (요약을 한 번은 다시 읽어야 하니까)
- 실제 가용 시간: 30분
- 받은 파일: 타행 예적금 금리 수집분 · 은행채 AAA 시가평가수익률 · 수신 마감실적 · 매일 채우는 양식 시트

**Claude Code가 없었다면?** (사전 업무파악에 적은 내 시간)
- 타행 사이트를 하나씩 돌며 금리 확인 (약 15분)
- 금투협 들어가 은행채 조회 (그 안에 포함)
- 실적을 양식에 옮기고 전일 대비 확인 (이슈 없으면 10분 이내)
- 큰 변동이 있으면 원인 찾기 (30분~1시간)
- 오늘처럼 은행채까지 시끄러운 날 — **1시간 넘게, 9시 반은 못 맞춘다**

**Claude Code가 있다면?**
- 파일과 지시서를 한 번에 넘긴다
- 양식이 채워지고, 변동이 표로 나오고, 원인 후보가 근거와 같이 붙는다
- 나는 후보를 읽고 **원인을 정한다** — 이건 여전히 내 일이다
- 목표: **9시 10분에 요약을 다시 읽고 있기**

자, 시작해보자.

## 미션 1: 금요일에 무슨 일이 있었나

마감실적 파일을 먼저 연다. 금요일 수신 합계 전일대비가 눈에 들어온다. 크지 않다. 평범한 날처럼 보인다.

**(속으로)**: 합계만 보면 조용하다. 근데 은행채가 이렇게 움직이는 주에 수신이 조용할 리가 없는데. 상품별로 열어봐야 안다.

**분석 요청**:
```
@sample-data/kakaobank/수신_마감실적_일별_2026-07-09.csv
@sample-data/kakaobank/타행_예적금금리_수집_2026-09.csv
@sample-data/kakaobank/은행채_AAA_시가평가수익률_2026-08-09.csv
@sample-data/kakaobank/일일_금리동향_마감실적_양식.xlsx
@templates/kakaobank/일일-금리-마감실적-체크.md 대로
금요일(9/18) 기준으로 양식 업데이트하고, 전일 대비 변동이랑 큰 변동의 원인 후보까지 정리해줘.
```

**결과 확인 후 추가 질문 예시**:
```
"원인 후보 두 개를 숫자로 나란히 놓아줘.
만기도래가 평소보다 얼마나 많았고, 그중 재예치가 평소 비율이었다면 얼마가 남았어야 했는지.
그 차이를 타행 인상으로 설명할 수 있는 크기인지도"
```

## 미션 2: 원인은 내가 정하고, 요약은 셋에게

9시 5분. 후보가 나왔다. 읽어 보니 한쪽은 파일 안에 근거가 있고, 한쪽은 아직 짐작이다.

**(속으로)**: 이건 내가 정해야 한다. 확인된 건 확인됐다고, 확인 중인 건 확인 중이라고 쓰자. 본부장님 요약에 짐작을 사실처럼 올리면 내일 협의회에서 그대로 굳는다.

**분석 요청**:
```
정기예금 변동은 만기도래 쪽을 첫 번째 후보로 두고 상태는 '확인 필요'로 둬. 근거 칸에 데이터팀에 물을 것 한 줄.
타행 인상은 금리 변동 행으로 따로 두고, 인상 사실만 '확인'.
그리고 팀장님·본부장님께 보낼 코코 요약본 초안을 숫자형·흐름형·헤드라인형 세 개로 만들어줘. 보내지는 마.
```

**결과 확인 후 추가 질문 예시**:
```
"아일라님께 드릴 한 줄도 만들어줘.
주담대 실적 예상에 쓰실 거니까 수신 실적 숫자는 빼고, 은행채 흐름이랑 타행 금리 움직임만.
사내 메신저라 문장마다 줄 바꿔서"
```

## 진행자 메모 — 자료에 대해

- **실제 값**: 은행채 = 금융투자협회 채권정보센터 「채권시가평가수익률 > 일자별」, 금융채 I(은행채) 무보증 AAA, 평가사 평균(`23.1.9~), 2026-08-03~09-18 (2026-09-21 조회). 타행 금리 9/21 수집분 = 금감원 금융상품통합비교공시 기본금리(공시월 202608, 2026-09-21 조회).
- **심은 값**: 타행 금리 두 건의 인상 전 값 — 토스뱅크 「먼저 이자 받는 정기예금」 12M 3.45(9/16까지), 케이뱅크 「코드K 정기예금」 12M 3.51(9/17까지). 실제 인상 여부·시점은 확인하지 않았다. 그 외 수집일 값은 9/21 조회값을 그대로 둔 것이다.
- **더미**: 수신 마감실적 전부, 양식 시트의 변동사유 기존 행. 실제 카카오뱅크 실적이 아니다.
- 코코 메시지·팀장님·아일라님 대사는 연습용으로 지은 것이다.
