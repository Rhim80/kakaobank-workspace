# 주간 매출 점검 보고 템플릿

> 온라인 채널 매출을 한 주 단위로 점검해 주간회의·사업부 공유용 보고를 만들 때 쓰는 양식.
> 호출: `@templates/slowbed/주간-매출점검-보고.md 관점으로`

---

## 사용 데이터

| 파일 | 왜 필요한가 |
|------|------------|
| `슬로우베드_온라인매출_2026.csv` | 주문 라인 단위 실적(`상품코드`·`정상가합계`·`할인액`·`실결제금액`). **취소·반품 건을 뺀 실매출**이 보고 기준이다. 라인 합계가 아니라 주문 단위로 세는 지표(주문수·객단가)를 헷갈리지 말 것 |
| `슬로우베드_상품마스터_2026.csv` | 품목별 정가·`자사몰판매가`·매입원가·물류단가(`상품코드` 기준). 매출을 **남는 장사였나**로 읽으려면 반드시 붙인다 |
| `채널운영마스터_2026.csv` | 채널별 `판매가율`·`판매수수료율`·`결제수수료율`·정산주기일·월광고비. 같은 100만원 매출도 채널마다 남는 돈이 다르다 |
| `프로모션_라이브_실행내역_2026.csv` | 행사·라이브 실행일(`행사코드`·`대상상품코드`)과 할인율·쿠폰액·광고비. **매출이 튄 날에 무엇이 있었나**를 붙이는 재료. 매출 CSV의 `프로모션코드`로 직접 조인된다 |
| `경쟁사_가격모니터링_2026.csv` | 동일 타입·사이즈 기준 타사 판매가·리뷰수·평점(`조사일` 기준 시점 데이터). "우리가 왜 밀렸나"의 절반은 여기 있다 |
| `네이버_리뷰_2026.csv` | 품목별(`상품코드`) 평점과 `부정키워드`·`리뷰유형`. 매출이 꺾이기 **전에** 먼저 움직이는 지표다 |

**조인 키는 `상품코드`(품목)·`채널`(채널운영마스터)·`프로모션코드`(행사 연동)다.** 매출만 보면 "얼마 팔았다"로 끝나고, 마스터만 보면 "마진율 몇 %"로 끝난다. 주간회의에서 실제로 나오는 질문은 *"올랐는데 왜 올랐고, 그게 남는 장사였고, 다음 주에 또 되느냐"* 다. 최소 세 파일(매출 × 상품마스터 × 채널운영마스터)을 붙여 **공헌이익까지** 계산한다.

**공헌이익 계산식** (이 순서로 계산한다):

```
실결제금액
 − 매입원가 × 수량
 − 물류단가 × 수량
 − 실결제금액 × (판매수수료율 + 결제수수료율)
 − 해당 기간 그 채널·품목에 집행된 월광고비 배분액
= 공헌이익
```

`판매가율`(채널운영마스터)은 정가 대비 그 채널의 정상 판매가 수준을 나타낸다 — 실제 이익 계산에는 `실결제금액`(할인 반영 후 확정액)을 쓰고, `판매가율`은 "이 채널이 원래 얼마에 파는 채널인지" 맥락 설명에만 참고한다.

취소·반품 주문은 매출·공헌이익 양쪽에서 뺀다. 반품은 물류단가가 **왕복으로** 발생하므로 반품 건의 물류비는 2배로 잡는다.

## 출력 구조

### 1. 한 줄 결론

이번 주가 지난주 대비 어땠는지를 **한 문장**으로. 숫자 두 개(매출 증감률·공헌이익률)를 문장 안에 넣는다.

예: "매출은 전주 대비 OO% 올랐지만 공헌이익률은 OO%p 내려갔다 — 사람은 더 샀는데 남는 돈은 줄었다."

숫자 하나만 든 결론은 반려다. **매출과 이익이 같은 방향으로 갔는지 아닌지**가 이 보고의 존재 이유다.

### 2. 핵심 지표

| 지표 | 이번 주 | 지난주 | 증감 | 그래서 |
|------|---------|--------|------|--------|
| 실매출 | | | | |
| 주문수 | | | | |
| 객단가 | | | | |
| 판매수량 | | | | |
| 공헌이익 | | | | |
| 공헌이익률 | | | | |
| 취소·반품률 | | | | |
| 신규:재구매 비중 | | | | |

**"그래서" 칸은 비우지 않는다.** 숫자만 있는 줄은 미완성으로 본다. 각 칸에 한 줄로 "이 숫자가 다음 주에 무엇을 바꾸는가"를 적는다. "전주 대비 +12%"는 값이지 해석이 아니다.

### 3. 채널별로 무슨 일이 있었나 (원인)

채널 하나마다 **3~4줄**로. 한 줄 요약 금지.

다음을 반드시 짚는다.

- **움직인 방향과 크기** — 매출·수량·공헌이익 세 축이 같은 방향인지. 갈렸으면 그게 이번 주의 핵심 사건이다.
- **왜 움직였나** — `프로모션_라이브_실행내역`에서 그 채널·그 기간에 걸린 행사·라이브·쿠폰·광고를 찾아 붙인다. 시즌(이사철·혼수·연휴)·경쟁사 가격 변동도 후보로 본다. **근거가 데이터에 있으면 그대로, 없으면 "(추정)"을 붙여 쓴다. 아무 근거도 없으면 "연동 근거 없음"이라고 쓴다.**
- **수수료·할인이 먹은 몫** — 매출이 늘어도 쿠폰·수수료가 그 이상 늘었으면 채널별 공헌이익률 하락폭을 숫자로 적는다.
- **다음 주에 그대로 두면** — 이 흐름이 이어질 때 무엇이 터지는지 한 줄.

### 4. 품목별 — TOP과 위험군을 같이 본다

- **매출 상위 5** — 순위만 나열하지 않는다. **왜 이 다섯이 위로 왔는지 공통점을 한 문단**으로 (사이즈·가격대·타입·행사 대상 여부·리뷰 평점).
- **공헌이익 상위 5** — 매출 상위와 **다르면 그 차이가 이 표의 핵심**이다. 많이 팔리는데 안 남는 품목이 어느 것인지 이름을 적는다.
- **하위 위험군** — 다음 넷 중 하나라도 걸리면 이름을 올린다.
  - 전주 대비 판매수량 30% 이상 감소
  - 공헌이익률 마이너스 또는 전체 평균의 절반 이하
  - 평점 4.0 미만이거나 이번 주 부정 리뷰 3건 이상
  - 경쟁사 동급 대비 판매가가 10% 이상 높음
  각각 "다음 주에 그대로 두면 무엇이 터지는가"를 한 줄로.

### 5. 튄 날 / 꺼진 날

일자별 매출에서 **기간 중앙값 대비 ±30%를 벗어난 날**을 전부 찾는다.

기준은 평균이 아니라 **중앙값**이다. 매트리스는 한 건이 400만원대인 품목이 섞여 있어 평균이 몇 건에 끌려간다. 평균을 쓰면 평범한 날이 "급락"으로 잡히고 진짜 급등일이 묻힌다.

각 날짜마다:
- 그날 걸려 있던 행사·라이브·쿠폰·광고를 `프로모션_라이브_실행내역`에서 찾아 붙인다 (라이브는 방송일 당일과 **다음 날까지** 본다)
- 어느 채널·어느 품목이 끌었는지 분해한다
- 그 스파이크가 **공헌이익도 같이 올렸는지** 확인한다. 매출만 튀고 이익이 안 튀었으면 그건 할인으로 산 매출이다
- 연동을 못 찾으면 "연동 근거 없음"이라고 쓴다. 억지로 이유를 붙이지 않는다

### 6. 타사 대비 (경쟁사 가격모니터링)

우리 주력 품목을 **동일 타입·동일 사이즈** 기준으로 타사와 나란히 놓는다. 사이즈가 다른 비교는 비교가 아니다.

- 가격 포지션 — 우리가 위인지 아래인지, 몇 % 차이인지
- 리뷰수·평점 — 가격이 높은데 평점도 높으면 유지 근거, 가격이 높은데 평점이 낮으면 그게 이번 주 리스크
- **가격만 보지 않는다** — 타사가 최근 가격을 내렸는지, 우리 판매 하락과 시점이 겹치는지

### 7. 회의용 코멘트 후보 3종

주간회의에서 쓸 한 문장을 **세 가지 형태로 미리 뽑는다.** 담당자가 자리에 맞는 것을 고른다.

- **숫자형** — 증감률과 금액을 앞세운 문장 (숫자에 밝은 자리)
- **흐름형** — "지난주에 이걸 했더니 이번 주에 이렇게 됐다"는 인과 문장 (원인을 묻는 자리)
- **헤드라인형** — 이번 주를 한 단어로 규정하는 문장 (시간이 없는 자리)

셋 다 채운다. "코멘트는 회의에서 채움" 같은 빈칸을 남기지 않는다.

### 8. 다음 주 액션

| 담당 | 액션 | 기한 | 우선순위 | 성공 기준 |
|------|------|------|---------|-----------|
| | | | | |

- **최소 3건, 최대 6건.** "3줄 이내로 요약"으로 뭉개지 않는다.
- 담당은 역할로 적는다 (온라인 MD / 브랜드마케팅 / SCM / 상품기획). 사람 이름은 쓰지 않는다.
- **성공 기준은 숫자로.** "개선한다"가 아니라 "다음 주 해당 품목 공헌이익률 OO% 이상".
- 우선순위는 상/중/하 대신 **1·2·3 순번**으로. 동점을 만들지 않는다.

## 검출 규칙 (이상 신호 임계값)

이 값을 넘으면 보고서에 **반드시 이름을 올린다.** 넘지 않으면 올리지 않는다.

| 신호 | 임계값 | 어느 섹션으로 |
|------|--------|--------------|
| 일 매출 급등 | 기간 일 매출 **중앙값** 대비 **+30% 이상** | §5 |
| 일 매출 급락 | 기간 일 매출 **중앙값** 대비 **−30% 이하** | §5 |
| 품목 판매 급감 | 전주 대비 수량 **−30% 이하** | §4 위험군 |
| 마진 누수 | 품목 공헌이익률 **0% 미만** 또는 전체 평균의 **절반 이하** | §4 위험군 |
| 채널 수익성 악화 | 채널 공헌이익률 전주 대비 **−3%p 이상** | §3 |
| 취소·반품 이상 | 품목 반품률 **8% 초과** | §4 위험군 |
| 리뷰 경고 | 평균 평점 **4.0 미만** 또는 주간 1~3점 리뷰 **3건 이상** | §4 위험군 |
| 가격 열위 | 경쟁사 동급 대비 판매가 **+10% 이상** | §6 |

**임계값을 넘은 항목이 하나도 없으면 "이번 주 임계값 초과 없음"이라고 명시한다.** 섹션을 통째로 지우지 않는다 — 안 걸렸다는 것도 정보다.

## 길이 제약

**A4 2~3장.** 표는 촘촘하게, 문장은 짧게.

단, **줄여도 되는 것과 안 되는 것을 구분한다.**
- 줄여도 되는 것: 표의 항목 수, 상위 품목 개수, 채널 나열
- **줄이면 안 되는 것: §2의 "그래서" 칸, §3의 원인 3~4줄, §5의 연동 근거, §7의 코멘트 3종, §8의 성공 기준.** 이것들이 이 보고를 보고서로 만드는 부분이다. 분량이 넘치면 숫자를 줄이지 해석을 줄이지 않는다.

## 톤 가이드

**온라인 담당자가 주간회의 자리에 내놓는 자료**다. 읽는 사람은 사업부 안의 동료들이고, 숫자를 이미 다른 화면에서 본 사람들이다. 그러니:

- **숫자를 다시 읽어주지 않는다.** 표에 있는 값을 문장으로 반복하는 대신, 그 숫자가 뜻하는 것을 쓴다.
- **숫자 옆에는 반드시 의미가 붙는다.** "네이버 3,200만원"이 아니라 "네이버 3,200만원 — 라이브 한 번이 주간 매출의 4할을 만들었다".
- **추정은 추정이라고 쓴다.** "(추정)" 표기 없이 원인을 단정하지 않는다.
- **모르는 것은 모른다고 쓴다.** "연동 근거 없음", "데이터 없음"이 빈칸보다 낫다.
- 경어체 없이 평서체로. 보고서지 메일이 아니다.
